🌍 WanderSnap – Travel Image Gallery

WanderSnap is a modern and responsive Travel Image Gallery web application built using React.js. It allows users to explore beautiful travel destinations through an interactive and visually appealing gallery.

✨ Features

- 🏠 Responsive Home Page with Hero Section
- 🖼️ Travel Image Gallery
- 🔎 Search destinations
- 🏷️ Category-based image filtering
- 📱 Fully responsive design
- 🧭 Separate Home and Gallery pages
- 📋 Mobile-friendly navigation menu
- 🖼️ Attractive image hover effects
- 🔗 React Router navigation
- 📌 Responsive Footer

🗂️ Categories

The gallery includes different travel categories such as:

- 🌿 Nature
- 🏖️ Beaches
- ⛰️ Mountains
- 🌆 Cities
- 🏛️ Historical Places
- 🐘 Wildlife

🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite
